Informasi Praktikum

Praktikum Pemrograman Web merupakan mata kuliah dengan tujuan mahasiswa diharapkan memahami pembuatan dan pengembangan halaman web menggunakan HTML, CSS, serta framework web.

Peserta praktikum diharapkan dapat mengikuti kegiatan dengan baik dan mengerjakan setiap tugas yang diberikan.
