    Inti materi

    API adalah cara sebuah program meminta layanan atau data dari program lain. GET dipakai untuk membaca data. fetch menghasilkan Response; response.json() membaca badan JSON menjadi nilai JavaScript. Periksa response.ok karena HTTP 404 atau 500 tidak otomatis membuat fetch masuk catch.

    Langkah mencoba

    1. Tekan Ambil pengguna.
    2. Amati daftar nama dan email yang muncul.
    3. Buka /api/users di tab browser untuk melihat JSON mentahnya.

    Hasil yang diharapkan

    Tiga pengguna contoh muncul dari API mock lokal.

    Latihan kecil

    Ubah tampilan setiap item menjadi hanya user.name.
