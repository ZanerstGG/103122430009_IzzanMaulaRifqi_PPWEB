Event dan XMLHttpRequest

Sumber data: ajax_info.txt

Inti materi

Event adalah kejadian seperti klik tombol. addEventListener menghubungkan kejadian itu dengan fungsi. Pada XHR, readyState 4 berarti proses selesai; status HTTP tetap harus diperiksa untuk mengetahui berhasil atau gagal.

Langkah mencoba

  1. Tekan Muat teks.
  2. Teks dalam file ajax_info.txt akan muncul.
  3. Edit ajax_info.txt, simpan, lalu tekan tombol lagi.

Hasil yang diharapkan

Isi ajax_info.txt muncul sebagai teks. Browser tidak berpindah halaman.

Latihan kecil

Ubah URL menjadi tidak-ada.txt, jalankan, lalu kembalikan. Anda akan melihat HTTP 404.
