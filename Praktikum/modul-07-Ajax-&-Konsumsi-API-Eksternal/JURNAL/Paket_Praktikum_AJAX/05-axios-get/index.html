Mengambil data yang sama dengan library Axios.

Coba program

Data belum diminta.

    Inti materi

    Axios adalah library pihak ketiga. Untuk response JSON, datanya langsung tersedia pada response.data. Secara bawaan, status di luar 200-299 ditolak dan dapat ditangani di catch. File Axios sudah tersedia di folder vendor, sehingga contoh ini tidak memerlukan CDN atau npm install.

    Langkah mencoba

    1. Tekan Ambil dengan Axios.
    2. Bandingkan hasilnya dengan contoh Fetch.
    3. Buka kode: perhatikan response.data dan pengaturan timeout.

    Hasil yang diharapkan

    Daftar yang sama muncul. Pada kode, tidak ada pemanggilan response.json().

    Latihan kecil

    Tambahkan ?mode=error ke URL request untuk mencoba catch. Setelah itu kembalikan URL.

    Lihat kode JavaScript: app.js

    File: 05-axios-get/app.js. Edit di VS Code atau editor teks, simpan, lalu refresh browser.
