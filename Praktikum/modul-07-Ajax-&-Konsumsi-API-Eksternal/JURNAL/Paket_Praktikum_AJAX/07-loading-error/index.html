Loading dan error handling

Menampilkan kondisi memuat, berhasil, kosong, gagal, dan timeout.

Coba program

Pilih skenario, lalu jalankan.

    Inti materi

    Pengguna perlu tahu apakah data sedang dimuat, sudah tersedia, atau gagal diambil. try berisi pekerjaan utama, catch menangani kegagalan, dan finally merapikan keadaan setelah selesai. Data kosong adalah response berhasil yang tidak berisi item.

    Langkah mencoba

    1. Pilih Berhasil, lalu tekan Jalankan. Amati teks Memuat.
    2. Ulangi dengan Error HTTP 503 dan Data kosong.
    3. Pilih Timeout untuk melihat request dibatalkan ketika batas waktu habis.

    Hasil yang diharapkan

    Setiap skenario menghasilkan pesan berbeda. Tombol selalu aktif kembali setelah selesai.

    Latihan kecil

    Ubah timeout 700 menjadi 3000. Skenario Timeout akan berhasil karena response tiba lebih dahulu.

    Lihat kode JavaScript: app.js

    File: 07-loading-error/app.js. Edit di VS Code atau editor teks, simpan, lalu refresh browser.
