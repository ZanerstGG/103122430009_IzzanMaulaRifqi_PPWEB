Cara kerja AJAX

Mengamati urutan event, request, response, dan perubahan DOM.

Coba program

    Belum ada request.

    Inti materi

    Browser mengirim request, server menyiapkan response, lalu JavaScript membaca response dan mengubah DOM. Asynchronous berarti browser dapat tetap melayani interaksi saat menunggu. await menunda kelanjutan fungsi async yang memakainya.

    Langkah mencoba

    1. Tekan Mulai request. API sengaja menunggu sekitar 1,5 detik.
    2. Selama menunggu, tekan Tambah hitungan beberapa kali.
    3. Baca urutan yang tercatat dan pesan hasilnya.

    Hasil yang diharapkan

    Urutan 1 sampai 5 tampil. Hitungan bisa bertambah ketika request masih berjalan.

    Latihan kecil

    Ubah delay=1500 menjadi delay=2500. Amati lama waktu menunggu.

    Lihat kode JavaScript: app.js

    File: 02-cara-kerja-ajax/app.js. Edit di VS Code atau editor teks, simpan, lalu refresh browser.
