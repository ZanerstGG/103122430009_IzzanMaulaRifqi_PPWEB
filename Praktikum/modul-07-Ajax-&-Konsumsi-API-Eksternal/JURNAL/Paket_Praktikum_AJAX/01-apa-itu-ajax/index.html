Apa itu AJAX?

Inti materi

AJAX adalah teknik meminta data ke server di belakang layar. Nama AJAX menyebut XML, tetapi datanya juga bisa berupa teks atau JSON. Fetch, XMLHttpRequest, dan Axios dapat dipakai untuk teknik ini.

Langkah mencoba

  1. Ketik catatan di kolom yang tersedia.
  2. Tekan Ambil pesan. Perhatikan hanya pesan hasil yang berubah.
  3. Catatan dan waktu halaman dibuka tetap sama selama request.

Hasil yang diharapkan

Pesan dari API lokal muncul. Isi catatan tetap ada dan waktu halaman dibuka tidak berubah.

Latihan kecil

Ubah teks tombol menjadi Ambil kabar. Muat ulang, lalu jalankan kembali.
