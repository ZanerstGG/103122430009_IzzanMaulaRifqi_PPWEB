POST dengan Axios

Mengirim nama dan email sebagai JSON ke API mock.

Coba program

Belum ada data dikirim.

Response akan muncul di sini.

Simulasi: data tidak disimpan. GET /api/users tetap berisi tiga pengguna awal.

Inti materi

POST mengirim data ke server. Axios mengubah objek JavaScript menjadi JSON dan mengatur Content-Type untuk objek biasa ini. Server latihan hanya mengembalikan data contoh dengan status 201; data tidak disimpan dan tidak akan ditambahkan ke daftar GET.

Langkah mencoba

  1. Isi nama dan email dengan data contoh.
  2. Tekan Kirim data.
  3. Perhatikan status 201 dan isi response JSON.

Hasil yang diharapkan

Response berisi id 101, nama, email, dan simulated: true. Pengiriman ini adalah simulasi.

Latihan kecil

Ubah nama dan kirim lagi. Bandingkan payload di Network dengan response dari server.
