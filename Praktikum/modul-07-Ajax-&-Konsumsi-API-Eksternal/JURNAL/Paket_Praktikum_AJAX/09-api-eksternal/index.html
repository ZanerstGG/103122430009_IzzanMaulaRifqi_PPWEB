API lokal dan API eksternal

Membandingkan request ke API mock dengan API publik JSONPlaceholder.

Coba program

Pilih sumber data, lalu jalankan.

    Inti materi

    API lokal berjalan di komputer sendiri. API eksternal berjalan pada server pihak lain dan memerlukan internet serta izin CORS yang sesuai dari server tersebut. Jika API eksternal gagal, Anda bisa memilih mock lokal secara manual untuk melanjutkan latihan.

    Langkah mencoba

    1. Jalankan dengan pilihan Mock lokal. Ini bekerja tanpa internet.
    2. Sambungkan internet, lalu pilih JSONPlaceholder dan jalankan lagi.
    3. Buka DevTools > Network untuk membandingkan URL dan response.

    Hasil yang diharapkan

    Mock mengembalikan tiga pengguna contoh. API eksternal menampilkan tiga pengguna pertama jika layanan dapat diakses.

    Latihan kecil

    Ganti slice(0, 3) menjadi slice(0, 5). Perubahan terlihat pada data eksternal yang memiliki lebih banyak pengguna.
