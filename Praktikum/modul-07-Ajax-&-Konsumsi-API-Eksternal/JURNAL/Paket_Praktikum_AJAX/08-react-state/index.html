Loading dan error di React

Menggunakan useState dan useEffect untuk mengambil dan menampilkan data.

Coba program

Inti materi

React memperbarui tampilan saat state berubah. useState menyimpan users, loading, dan error. useEffect menjalankan request setelah render awal dan setiap dependensinya berubah. Cleanup membatalkan request lama saat mode berubah atau komponen dilepas.

Langkah mencoba

  1. Buka contoh ini. Data diminta otomatis oleh useEffect.
  2. Pilih Error HTTP 503 atau Data kosong.
  3. Kembali ke Berhasil atau tekan Muat ulang data. Anda juga boleh mengganti mode saat loading.

Hasil yang diharapkan

React menampilkan loading, daftar, pesan error, atau data kosong sesuai skenario.
